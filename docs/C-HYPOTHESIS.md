# Hypothèse C — définition conceptuelle consolidée

## 1. Statut du document

Ce document fixe le sens physique attribué à **C** avant toute formalisation mathématique détaillée.

Il décrit une hypothèse de travail. Il ne constitue ni une théorie physique établie, ni une dérivation de la relativité générale, ni une interprétation complète de la mécanique quantique.

L'objectif est de conserver une séparation stricte entre :

1. les postulats conceptuels ;
2. les quantités opérationnelles que l'on peut calculer ;
3. les structures mathématiques qui seront éventuellement introduites pour les représenter ;
4. les tests capables de réfuter le modèle.

---

## 2. Nature de C

L'hypothèse de départ est qu'une particule élémentaire porte un **état géométrique local** noté `C`.

`C` n'est pas :

- une position ;
- une vitesse ;
- une énergie ;
- le temps lui-même ;
- une évolution de l'état quantique.

`C` représente la **géométrie spatiale associée à une unité locale de temps**, c'est-à-dire l'extension géométrique dans laquelle une propagation physique peut se manifester relativement à cette unité.

Cette géométrie peut être isotrope ou déformée suivant plusieurs directions. Sa représentation complète est donc supposée pouvoir être tridimensionnelle. Une représentation tensorielle locale, notée provisoirement

\[
C_{ij},
\]

est une candidate naturelle, mais son caractère tensoriel reste à démontrer opérationnellement.

Le cas isotrope constitue une réduction particulière :

\[
C_{ij}=C\,\delta_{ij}.
\]

---

## 3. C et unité locale de temps

`C` décrit un état géométrique ; il n'est ni une durée ni une évolution temporelle.

Il associe à l'unité locale de temps de référence une extension géométrique possible de propagation. La durée fournit l'unité de référence ; `C` en exprime la représentation géométrique dans l'espace.

Cette définition n'impose aucune structure temporelle particulière au-delà de cette relation locale entre unité de temps et extension géométrique.

---

## 4. Normalisation de référence

La valeur

\[
C=1
\]

est une **normalisation de référence**.

Elle ne signifie pas « vide absolu ». Le modèle ne suppose pas qu'un tel état soit physiquement accessible ou même nécessaire à sa définition.

`C = 1` correspond à l'état de référence dans lequel la borne locale de propagation causale est notée

\[
c.
\]

La valeur numérique de `c` dépend évidemment des unités choisies ; le contenu physique recherché est l'existence d'une borne causale locale.

Dans une réduction isotrope et relativement à l'état de référence, une écriture opérationnelle candidate est

\[
v_{\mathrm{eff}} = C\,c.
\]

Cette expression ne doit pas être interprétée comme une variation directement observable de `c` par un observateur local immergé dans le même état collectif.

---

## 5. C et propagation de l'information

La propagation de l'information n'est pas supposée se dérouler dans une géométrie préalable indépendante de `C`.

L'hypothèse est inverse : `C` fournit une **représentation géométrique locale des possibilités de propagation** associées à l'unité temporelle de référence.

Dans un état isotrope, les directions sont géométriquement équivalentes.

Dans un état anisotrope, certaines directions peuvent correspondre à des extensions géométriques différentes. `C` ne sélectionne toutefois pas à lui seul la direction effectivement suivie par l'information : il décrit la géométrie des possibilités de propagation.

Dans le cas isotrope, l'identité algébrique

\[
n_{\mathrm{eff}} = \frac{1}{C}
\]

peut être utilisée comme analogie avec un indice de réfraction effectif. Cette analogie ne constitue pas une identité ontologique : le modèle ne postule pas un milieu optique classique dans un espace préexistant.

---

## 6. Invariance locale de c : exigence, non résultat acquis

L'intuition physique impose qu'un observateur appartenant entièrement à une région collectivement uniforme en `C` mesure localement la même borne causale `c`.

L'observateur, ses atomes, ses règles, ses horloges et les processus physiques utilisés pour la mesure sont tous soumis au même environnement collectif.

Cependant, le modèle ne doit pas considérer

\[
c_{\mathrm{local}}=c
\]

comme une tautologie déjà démontrée.

Il s'agit d'un **principe de cohérence que la formalisation devra reproduire** en montrant comment les étalons spatiaux et temporels dépendent de l'état collectif associé à `C`.

---

## 7. Dépendance de C à l'environnement quantique

Le `C` porté par une particule n'est pas supposé être une propriété fixe indépendante du reste du système.

Son état dépend de l'environnement quantique collectif auquel la particule appartient.

L'hypothèse actuelle est que les degrés de liberté de matière et de jauge, ainsi que leurs corrélations physiques, participent à la détermination de `C`.

Le modèle ne doit pas dépendre de variables de jauge non observables. Les quantités candidates doivent être **invariantes de jauge**.

La chaîne conceptuelle est donc :

\[
|\Psi_{\mathrm{ensemble}}\rangle
\longrightarrow
\text{observables et corrélations invariantes de jauge}
\longrightarrow
C.
\]

La fonction qui réalise cette projection est inconnue. On la note provisoirement

\[
C = \mathcal G(|\Psi\rangle).
\]

`\mathcal G` constitue l'un des objets centraux à déterminer expérimentalement ou dans un modèle jouet.

---

## 8. C ne produit pas la mécanique quantique

Le modèle ne propose pas de faire dériver la mécanique quantique de `C`.

La mécanique quantique conserve la description de :

- l'état ;
- les amplitudes ;
- les phases ;
- les superpositions ;
- les corrélations ;
- les probabilités de mesure.

`C` est envisagé comme une **représentation géométrique de certaines propriétés de l'état quantique**.

Schématiquement :

\[
\begin{array}{c}
|\Psi_{\mathrm{ensemble}}\rangle\\[1mm]
\swarrow\qquad\searrow\\[-1mm]
\text{amplitudes / corrélations}
\qquad
C\\
\qquad\qquad\downarrow\\
\qquad
\text{géométrie des possibilités}
\end{array}
\]

La statistique quantique et la géométrie de `C` sont donc complémentaires, pas concurrentes.

---

## 9. Niveau individuel et niveau relationnel

L'intuition initiale attribue un état géométrique à chaque particule :

\[
C^{(p)}.
\]

Mais cet état n'est physiquement accessible qu'à travers les relations de `p` avec les autres constituants.

On introduit donc un second niveau, opérationnel et relationnel :

\[
C^{(pq)},
\]

qui décrit une manifestation effective de `C` dans la relation entre `p` et `q`.

Le modèle ne tranche pas encore entre les trois possibilités suivantes :

1. `C` est fondamentalement une propriété de nœud ;
2. `C` est fondamentalement une propriété de relation/lien ;
3. les deux descriptions correspondent à deux niveaux d'une même structure, avec un `C^{(p)}` effectif reconstruit à partir des `C^{(pq)}`.

Cette troisième lecture est actuellement une candidate particulièrement naturelle :

\[
\{C^{(pq)}\}_q
\longrightarrow
C^{(p)}_{ij}.
\]

Le tenseur local serait alors une structure effective reconstruite à partir de plusieurs relations, et non nécessairement un objet imposé dès le départ.

---

## 10. Géométrie collective

La géométrie macroscopique n'est pas définie comme une somme directe des `C` individuels.

Elle est recherchée comme une structure effective issue de l'organisation collective des relations de propagation :

\[
\{C^{(pq)}\}
\longrightarrow
\text{structure géométrique effective}
\longrightarrow
\text{géométrie macroscopique}.
\]

Un ensemble statistiquement homogène pourrait produire une géométrie macroscopiquement uniforme.

Des variations relationnelles cohérentes pourraient produire une géométrie effective non uniforme ou courbée.

Le modèle doit avoir le droit d'échouer à cette étape. Si aucune structure métrique ou tensorielle stable ne peut être reconstruite à partir des `C^{(pq)}`, l'hypothèse géométrique devra être révisée.

---

## 11. Observabilité adimensionnelle

Une valeur telle que

\[
C=0.8
\]

n'a de contenu opérationnel que relativement à un état de référence.

Le premier modèle doit donc privilégier des observables **sans dimension**.

Une candidate minimale entre deux sites ou régions `p` et `q` est :

\[
C^{(pq)}_{\mathrm{eff}}
=
\frac{T^{\mathrm{ref}}_{pq}}
     {T^{\mathrm{state}}_{pq}},
\]

où `T` représente un temps d'arrivée défini par une observable invariante de jauge.

Ainsi :

\[
T^{\mathrm{state}}_{pq}=T^{\mathrm{ref}}_{pq}
\Rightarrow
C^{(pq)}_{\mathrm{eff}}=1,
\]

et

\[
T^{\mathrm{state}}_{pq}=1.25\,T^{\mathrm{ref}}_{pq}
\Rightarrow
C^{(pq)}_{\mathrm{eff}}=0.8.
\]

Cette définition est une **sonde opérationnelle candidate**, pas encore la définition fondamentale de `C`.

---

## 12. Covariance et absence de repère privilégié

Un tenseur spatial `C_{ij}` soulève immédiatement une question : dans quel repère ses composantes sont-elles définies ?

Le modèle ne doit pas introduire implicitement un repère spatial global privilégié.

Il faudra donc établir une règle cohérente permettant de comparer ou de composer les structures associées à des constituants en mouvement relatif.

Le caractère relationnel de `C^{(pq)}` peut réduire ce problème dans le modèle discret, mais ne constitue pas encore une démonstration de covariance relativiste dans la limite continue.

---

## 13. Portée limitée de l'émergence

Un modèle quantique défini sur un graphe ou un réseau possède déjà une connectivité imposée.

Par conséquent, si `C` est reconstruit à partir de corrélateurs calculés sur cette structure, le premier résultat possible est :

\[
\text{état quantique sur une topologie donnée}
\longrightarrow
\text{géométrie effective sur cette topologie}.
\]

Il ne faut pas présenter cela comme l'émergence complète de l'espace ou de la topologie elle-même.

L'émergence de la connectivité fondamentale constitue une question ultérieure et distincte.

---

## 14. Bornes et monotonie

L'intuition actuelle envisage, dans la réduction isotrope de référence,

\[
0 < C \le 1.
\]

La borne supérieure encode la normalisation associée à la propagation causale maximale.

Elle ne fixe pas à elle seule le caractère attractif ou répulsif d'une dynamique géométrique.

Le postulat plus fort serait une loi universelle du type

\[
\text{augmentation de matière / interaction}
\Rightarrow
C\text{ diminue}.
\]

Cette monotonie n'est pas encore établie et devra être testée plutôt que supposée comme loi générale.

---

## 15. Rapport à la relativité générale

Dans sa forme actuelle, `C` ne remplace pas une métrique d'espace-temps complète.

Un tenseur spatial tridimensionnel, même anisotrope, ne contient pas automatiquement tous les degrés de liberté nécessaires à une géométrie relativiste générale.

Le modèle doit donc déterminer si les informations temporelles et les effets liés au mouvement des sources émergent de l'organisation collective de `C`, ou s'ils nécessitent des degrés de liberté supplémentaires.

Il faut également éviter de simplement redéfinir sous un autre nom une décomposition connue de la métrique.

La valeur ajoutée physique éventuelle de l'hypothèse C se trouverait dans une dérivation de la structure géométrique à partir de l'état quantique collectif, et dans des prédictions testables qui ne soient pas de simples reformulations.

---

## 16. Critères minimaux de falsifiabilité

Une fois une première définition calculable de `\mathcal G` obtenue, le modèle devra être contraint rapidement.

Une progression naturelle est :

1. comportement relationnel dans un modèle quantique fini ;
2. existence ou non d'une structure géométrique reconstructible ;
3. limite faible compatible avec une dynamique de type newtonien ;
4. propagation de la lumière avec la correction complète attendue ;
5. délai de Shapiro ;
6. effets liés au mouvement et à la rotation des sources ;
7. tests de covariance et de limite relativiste.

Un échec à l'un de ces niveaux doit pouvoir réfuter ou restreindre la forme considérée de `C`.

---

## 17. Résumé du programme

La chaîne de travail actuelle est :

\[
\boxed{
|\Psi_{\mathrm{ensemble}}\rangle
\rightarrow
\text{corrélations invariantes de jauge}
\rightarrow
C^{(pq)}_{\mathrm{eff}}
\rightarrow
C^{(p)}_{ij}\ ?
\rightarrow
\text{géométrie effective}\ ?
}
\]

Les points d'interrogation sont intentionnels.

Le premier objectif n'est pas de confirmer l'hypothèse, mais de construire un modèle minimal dans lequel cette chaîne peut être testée et, si nécessaire, falsifiée.
